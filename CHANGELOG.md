# Changelog

All notable eXcap changes are documented here.

## [1.0.0] - 2026-07-30

### Added

- eXcap application identity (`app.excap.network`) and 1.0 semantic version.
- Original network-node logo, launcher assets, TV banner, navy/mint visual system, and redesigned status dashboard.
- Privacy-forward VPN consent and onboarding copy.
- Clear plaintext HTTP versus encrypted HTTPS/TLS capability boundaries.
- Professional architecture, privacy, security, testing, attribution, and build documentation.
- GitHub Actions validation with unit tests, lint, APK build, checksum, artifacts, and tagged releases.

### Changed

- Product-facing PCAPdroid branding is replaced by eXcap while upstream source attribution and GPL notices remain intact.
- Default export prefix and download directory are now `eXcap_` and `Downloads/eXcap`.
- The first release packages only reviewed English product resources.
- Navigation focuses on capture, diagnostics, settings, documentation, and attribution.

### Engine baseline

- Built on the PCAPdroid capture engine and its pinned native submodules.
